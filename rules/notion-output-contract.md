# 노션 출력 계약

사용자가 노트를 노션으로 받겠다고 할 때만 읽는다. 기본 출력(자료 충실형 Markdown, 심화 이해형 PDF)은 바뀌지 않는다. 지금은 자료 충실형 Markdown 노트를 올린다. 심화 이해형의 슬라이드 이미지·토글·식 번호는 아직 지원하지 않는다.

## 토큰과 연결

- 처음 한 번은 사용자가 직접 한다: 노션 개발자 도구에서 연결(인증 방법 API 토큰, 콘텐츠 읽기·업데이트·입력만) 만들기, 자기 터미널에서 `gongbu notion login`, 상위 페이지를 만들어 그 연결 추가. 연결은 사용자가 연결해 준 페이지 아래에만 쓸 수 있어 첫 상위 페이지는 에이전트가 만들 수 없다. 절차는 `../docs/install.md`의 노션 절이다.
- 에이전트는 토큰을 묻거나 채팅으로 받지 않고, 읽거나 출력하지 않으며, `login`을 실행하지 않는다. 토큰이 없다는 오류가 나면 사용자에게 위 절차를 안내한다.
- 과목 연결은 과목 폴더에서 `gongbu notion setup <상위 페이지 링크> --course <과목명>`이다. 웹에 공개된 상위 페이지는 거부한다. 페이지·표 ID만 `.gongbu/notion.json`에 남는다.

## 원고

- 지금의 자료 충실형 Markdown을 그대로 쓴다. 맨 앞 `# 과목 N주차 — 주제`가 표의 줄 제목(`N주차 · 주제`), `##` 차시 제목들이 '내용' 칸이 된다. 노션에서는 제목 단계를 하나씩 올린다(`##` → 제목 1).
- 강조 상자는 `> [!NOTE]`(💡 파랑), `> [!WARNING]`(⚠️ 주황), `> [!TIP]`(📌 초록)으로 쓰고, 첫 줄을 `**이름**`으로 쓰면 상자 제목이 된다. 예전 `> 주의:` 상자도 주황 상자로 간다.
- 불확실성 표시(`[확인 필요]`, `[전사 불명확]` 등)는 노란 형광으로 올라간다. 추적 주석과 인계 메모는 올리지 않는다.
- 로컬 파일 링크는 글자만 남고, 그림은 캡션 글자만 올라간다. 수식 하나는 1000자까지다.

## 올리기

1. `gongbu notion check <노트.md>`로 네트워크 없이 변환·검사한다. `오류:`가 있으면 원고를 고친다.
2. `gongbu notion push <노트.md> --dry-run`의 위치·할 일·내용을 사용자에게 보여 주고 확인을 받는다. 노션은 외부 서비스이므로 확인 없이 올리지 않는다. 이전 확인을 다른 노트에 재사용하지 않는다.
3. `gongbu notion push <노트.md>`(교안 범위를 알면 `--handout "교안 01·02"`)로 올리고 페이지 링크를 전달한다. 올린 페이지는 사용자가 노션에서 열어 확인한다. 검사 통과는 시각 확인이 아니다.

다시 올리면 Python이 정한다: 그대로면 건너뛰고, 표 속성만 바뀌면 속성만 고친다. 원고가 바뀌었고 노션에서 아무도 고치지 않았으면 새 줄로 올리고 이전 줄은 휴지통으로 보낸다. 노션에서 고친 흔적이 있으면 덮어쓰지 않고 "(수정본 N)"으로 새 줄을 만든다. 올리는 중 실패하면 만들던 줄을 휴지통으로 보내고 로컬 원고는 그대로 둔다.

녹음, 전사본, source map, 대응표, 내부 작업 기록은 올리지 않는다.
