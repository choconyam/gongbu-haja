# Note Production Modes

학습노트 제작 모드는 과목 분류가 아니라 설명을 어디까지 보강할지 정하는 사용자 선택값이다. 한 강의 실행에는 `faithful` 또는 `deep` 중 하나만 기록한다. `content-modes.md`의 STEM·인문사회·코드 등 자료별 설명법은 선택된 제작 모드의 범위 안에서 적용한다.

## 1. 모드 선택

| 내부 값 | 사용자 표시 | 적합한 목적 |
|---|---|---|
| `faithful` | 자료 충실형 | 교안과 교수 설명을 빠르게 정리해 암기·복습할 때 |
| `deep` | 심화 이해형 | 과목 분야와 관계없이 배경 맥락, 원인·관계, 중간 사고, 유도나 적용 판단까지 깊게 이해할 때 |

- 새 노트를 시작할 때 사용자가 말한 모드를 우선한다. `자료 충실형`, `암기형`, `빠른 정리`는 `faithful`로, `심화 이해형`, `유도 포함`, `배경 설명 포함`은 `deep`으로 해석할 수 있다.
- 새 학습노트 요청마다 사용자가 모드를 명시하지 않았다면 실행 상태를 만들기 전에 반드시 두 모드 중 하나를 선택받는다. 자료 특성을 근거로 하나를 추천할 수 있지만 과목명이나 계열만으로 대신 결정하지 않는다.
- 명령행 초기화에서는 `--note-mode faithful|deep`로 기록한다. 필수 인자이므로 생략하면 초기화가 거부되고, 관리자는 먼저 사용자에게 선택을 받아야 한다.
- 제작 모드를 바꿀 때는 입력·전사·자료 매핑을 다시 만들지 않고 `set-mode`로 집필 이후만 무효화한다.

```powershell
python scripts/manage_run.py set-mode workspace/<강의ID>/run_state.json --note-mode deep --reason "수식 유도와 배경 설명 필요"
```

## 2. 자료 충실형 (`faithful`)

- 사실 범위는 교안, 검수된 교수 설명, 사용자가 지정한 참고자료로 제한한다.
- 원자료의 정의, 수치, 분류, 인과관계, 교수 강조점과 시험 조건을 왜곡 없이 압축한다.
- 교안의 문장을 반복하기보다 교수 설명을 붙여 암기 단위, 대비표, 순서, 핵심 문장으로 정리한다.
- 원자료에 없는 배경지식, 새 사례, 표준 유도, 확장 해석, 외부 검색 결과는 기본적으로 추가하지 않는다.
- 이해에 필요한 연결어는 쓸 수 있지만 원자료가 말하지 않은 이유나 결론을 만들어내지 않는다.
- 수식·코드 검수 역할이 필요하면 원자료와 계산의 정확성만 확인하며 새로운 장문 튜토리얼로 확장하지 않는다.
- `pedagogy_editor`는 기본 비활성이다. 명백한 문장 연결 문제를 고칠 때만 범위를 제한해 수동 활성화한다.
- 기본 최종 형식은 Markdown이다(`manage_run.py init`에서 `--output-format` 생략 시). 바로 열어 읽고 고치는 용도이며, 인쇄가 필요하면 사용자가 pdf를 지정한다. 심화 이해형의 기본은 pdf다.
- 작성은 `quality_high`(상위 모델)로 수행한다. 경량 모델 집필은 교수 설명을 축약해 재작업을 부르므로 쓰지 않는다. 독립 최종 검수는 `review_high`(상위 모델 `high`)로 모든 source unit을 대응 노트 위치와 대조하며, Python coverage 게이트가 누락·중복·근거 없는 제외를 차단한다.
- 최종 `review_high` 완성본 대조는 현재 `review_cycle`에서 한 번만 수행하고, 발견한 국소 문제는 같은 호출 안에서 수정·해당 위치만 재확인한다.

## 3. 심화 이해형 (`deep`)

- 원자료의 핵심 흐름을 보존하면서 독자가 건너뛰기 어려운 배경 개념과 중간 사고를 보강한다.
- 수식은 출발식, 사용한 법칙, 중간 변형, 가정, 단위, 결과 해석과 적용 조건을 필요한 범위에서 보여준다.
- 그래프·도식·코드는 무엇을 보고 어떤 판단을 해야 하는지 단계별로 설명한다.
- 작은 예시, 검산, 반례, 관련 선행개념을 추가할 수 있다. 원자료에 없는 내용은 `보충 설명`처럼 명확히 구분하고 검증한다.
- 이공계에서는 중간식·유도·검산이, 인문사회·예술·언어 과목에서는 시대 배경·인과관계·논쟁 맥락·개념 비교가 심화 설명이 될 수 있다.
- 자료에 근거가 없는 교수 의도나 시험 출제를 추측하지 않는다.
- `pedagogy_editor`를 기본 활성화한다. 수식·코드·그래프가 있으면 `formula_code_checker`를 활성화하거나 자료 매핑 뒤 필요한 범위를 지정한다.
- 작성·교수 설명 통합·교육 보강·수식 의미 검수는 `quality_high`로 수행한다. 독립 최종 검수는 `quality_xhigh`로 완성본 전체를 한 번 읽어 논리·유도·설명 연결을 확인한다.
- 최종 `quality_xhigh` 완성본 검수는 현재 `review_cycle`에서 한 번만 수행하고, 발견한 국소 문제는 같은 호출 안에서 수정·해당 위치만 재확인한다.

## 4. 역할별 전달 계약

- 관리자는 모든 역할 요청에 `note_mode`, 사용자 표시명, 허용된 보강 범위를 포함한다.
- 자료 매핑 담당은 원자료 사실과 교수 설명을 분리해 두 모드 모두 같은 근거를 재사용할 수 있게 한다.
- 작성 담당은 `faithful`에서 근거 밖 보강을 만들지 않고, `deep`에서만 검증된 보충 설명을 구분해 추가한다.
- 조판 담당은 모드와 관계없이 내부 페이지·타임스탬프 포인터를 학생용 결과에 노출하지 않는다.
- 최종 검수 담당은 사실 정확성뿐 아니라 선택 모드의 범위를 지켰는지 확인한다. `faithful`의 불필요한 외부 보강과 `deep`의 빠진 핵심 유도·중간 사고는 각각 수정 사유다.
- 최종 검수 담당은 모든 `source_unit_id`를 coverage report에 정확히 한 번 기록한다. Python은 ID·결정·필수 위치와 이유를 검사하지만, 누락·왜곡·설명 품질의 의미 판정은 각 모드의 독립 검수 에이전트가 담당한다.

## 5. 토큰 통제

- 두 모드 모두 전사와 PDF 추출은 로컬 도구로 한 번만 수행한다.
- `faithful`은 페이지별 근거 구간과 대응표만 사용하고 설명 보강 역할을 기본 생략한다.
- `deep`도 전체 원시 전사를 반복 전달하지 않는다. 현재 단원의 근거 구간과 필요한 선행개념만 전달한다.
- 모드 변경은 `writer` 이후만 다시 실행한다. 녹음, 전사 검수, 교안 정렬과 자료 매핑의 해시가 같으면 그대로 재사용한다.
