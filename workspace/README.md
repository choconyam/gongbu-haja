# Workspace

이 폴더는 강의별 전사·자료 매핑·초안·검수 중간 산출물을 둔다. 원본 교안과 녹음을 이 폴더로 강제 이동하지 않으며, 원본 경로와 해시는 강의 manifest에 기록한다.

기본 전사 경로:

```text
workspace/<lecture_id>/transcript/
```

동일한 `lecture_id`의 기존 산출물은 `--force` 없이는 덮어쓰지 않는다. 최종 학습노트는 사용자가 지정한 위치에 전달하고, 이 폴더의 중간 산출물은 자동 삭제하지 않는다.

`run_state.json.lock`은 같은 강의 상태의 동시 수정을 막는 락 파일이다. 명령이 끝나면 자동으로 사라지며, 실행 중인 세션이 없는데도 남아 있다면 중단된 실행의 흔적이므로 삭제해도 된다.
